# DNS Auto

Автоматическое обновление DNS-настроек на роутере.

Скрипт `dns-auto` запускается через `cron` и автоматически выполняет необходимые DNS-действия каждые 5 минут. Подходит для роутеров на Linux/OpenWrt, где доступно выполнение shell-скриптов и `cron`.

## 📦 Установка

### 1. Скачать скрипт

**[⬇️ Скачать dns-auto](./dns-auto.bash)**

Сохраните файл `dns-auto.bash`, например, на рабочий стол Windows.

---

## 🪟 Установка с Windows через PowerShell

### 2. Загрузить скрипт на роутер

Откройте **PowerShell** и выполните:

```powershell
scp -O "$env:USERPROFILE\Desktop\dns-auto.bash" root@192.168.9.1:/usr/bin/dns-auto
```

> **Важно:** `192.168.9.1` - пример IP-адреса роутера.
> Замените его на IP-адрес вашего роутера, если он отличается.
> Если по какой то причине, ip роутера вам не известен, вместо ip адреса можно использовать `openwrt.lan`, например:
```powershell
scp -O "$env:USERPROFILE\Desktop\dns-auto.bash" root@openwrt.lan:/usr/bin/dns-auto
```

После выполнения команды файл будет загружен в:

```text
/usr/bin/dns-auto
```

---

### 3. Подключиться к роутеру по SSH

Подключитесь к роутеру:

```powershell
ssh root@192.168.9.1
```

Если IP-адрес роутера отличается — замените его в команде.

---

### 4. Исправить окончания строк CRLF

Так как файл был создан в Windows, он может содержать окончания строк `CRLF` и будут лететь ошибки при попытке запустить его.

Linux использует `LF`, поэтому перед запуском скрипта необходимо удалить `\r`:

```sh
sed -i 's/\r$//' /usr/bin/dns-auto
```
---
### 6. Для запуска скрипта нужно выдать ему права на выполнение

```sh
chmod +x /usr/bin/dns-auto
```

---

## ⏱️ Автоматический запуск через Cron

### 6. Добавить скрипт в Cron

Откройте таблицу заданий:

```sh
crontab -e
```

Добавьте строку:

```cron
*/5 * * * * /usr/bin/dns-auto
```

Это означает, что скрипт будет запускаться **каждые 5 минут**.

Сохраните файл и выйдите из редактора.

---

### 7. Перезапустить Cron

После изменения расписания перезапустите службу `cron`:

```sh
/etc/init.d/cron restart
```

---

## 🔍 Проверка работы

### 8. Запуск скрипта

Запускаем скрипт вручную, чтобы проверить, что все запускается и он готов к работе

```sh
/usr/bin/dns-auto
```

### 9. Посмотреть лог

Чтобы убедиться, что скрипт запускается и работает корректно:

```sh
cat /var/log/dns-auto.log
```

Для наблюдения за логом в реальном времени можно использовать:

```sh
tail -f /var/log/dns-auto.log
```

Если в логе появляются ожидаемые записи — автоматический запуск настроен успешно.

---

## 📋 Быстрая установка

Если SSH-доступ к роутеру уже настроен, основные команды выглядят так:

```powershell
scp -O "$env:USERPROFILE\Desktop\dns-auto.bash" root@192.168.9.1:/usr/bin/dns-auto
ssh root@192.168.9.1
```

После подключения к роутеру:

```sh
sed -i 's/\r$//' /usr/bin/dns-auto

crontab -e
```

Добавить:

```cron
*/5 * * * * /usr/bin/dns-auto
```

Затем:

```sh
/etc/init.d/cron restart
chmod +x /usr/bin/dns-auto
/usr/bin/dns-auto
cat /var/log/dns-auto.log
```

---


## ⚙️ Требования

* Linux/OpenWrt-роутер
* SSH-доступ к роутеру
* установленный и работающий `cron`
* доступный `sed`
* права `root` для установки скрипта и настройки cron

---

## ⚠️ Примечания

* Перед установкой убедитесь, что `/usr/bin/dns-auto` не занят другим файлом.
* Если IP роутера отличается от `192.168.9.1`, замените его в командах `scp` и `ssh`.
* После изменения скрипта не забудьте повторно загрузить его на роутер.
* Если скрипт не запускается, в первую очередь проверьте содержимое `/var/log/dns-auto.log`.
